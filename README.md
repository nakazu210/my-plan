# マイプラン

ラン・勉強・資金づくりの計画と記録をまとめるカレンダーアプリです。
見た目はGoogleカレンダー風で、iPhone Duoの「閉じた画面（1列）」と「開いた画面（左右2画面）」に合わせて自動で切り替わります。

## できること

- 予定・記録の種類：ラン／勉強／資金／その他
- 予定ごとに、Googleカレンダーへの同期先を選べる
  - **アプリだけ**：このアプリにだけ残す
  - **自分のカレンダー**：自分専用の「ラン計画」「勉強計画」「資金計画」「マイプラン」カレンダーに入れる（妻には見えない）
  - **夫婦の共有カレンダー**：妻と共有しているカレンダーに入れる
- 夫婦の共有カレンダーの予定も、灰色で一緒に表示（見るだけ）
- 「まとめ」で、月のラン距離・ペース、勉強時間・試験までの日数、資金の達成率を表示

## しくみ

| 部分 | 置き場所 |
|---|---|
| 画面（index.html・style.css・app.js） | GitHub Pages |
| データ保存とカレンダー連携（gas/Code.gs） | 本人のGoogleアカウントの Apps Script |
| データ本体 | Googleスプレッドシート「マイプラン データ」 |

- Googleとつなぐ前は「お試し表示」（端末の中だけで動く見本データ）になります
- 本番ではGoogleアカウントでログインします（持ち主のアカウントだけが使えます）
- 色のテーマは設定で「自動／ライト／ダーク」から選べます

## 初回セットアップ（Google側・本人操作）

### A. Apps Script（データ保存とカレンダー連携）
1. https://script.google.com →「新しいプロジェクト」→ 名前を「マイプラン」に
2. 中身をすべて消し、`gas/Code.gs` を貼り付けて保存
3. 歯車（プロジェクトの設定）でタイムゾーンが「(GMT+09:00) 東京」か確認
4. 関数 `setup` を選んで「実行」→ 許可（「確認されていません」と出たら「詳細」→「移動」→「許可」）
   - カレンダー4つ（ラン計画・勉強計画・資金計画・マイプラン）とスプレッドシートが自動で作られます
5. 「デプロイ」→「新しいデプロイ」→ ウェブアプリ（実行：自分／アクセス：全員）→ `/exec` で終わるURLを控える

### B. Googleログインの登録（Google Cloud）
1. https://console.cloud.google.com → 新しいプロジェクト「マイプラン」
2. 「APIとサービス」→「OAuth同意画面」（Google Auth Platform）→ アプリ名「マイプラン」・自分のメールで作成（対象：外部）
3. 「対象」→ テストユーザーに自分のGmailを追加
4. 「クライアント」→「クライアントを作成」→ 種類「ウェブ アプリケーション」
   - 承認済みのJavaScript生成元：`https://nakazu210.github.io`
5. 表示された「クライアントID」（…apps.googleusercontent.com）を控える

### C. 仕上げ（Claude Codeが実施）
- `config.js` に A のURLと B のクライアントIDを、`gas/Code.gs` の `CLIENT_ID` にクライアントIDを入れて公開し直す
- Apps Script に新しい Code.gs を貼り直し、「デプロイを管理」→ 新バージョンで更新

その後アプリを開き、「Googleでログイン」→ 設定で夫婦の共有カレンダーを選ぶ。

- ログインできるのは、Apps Scriptの持ち主のGoogleアカウントだけです（端末ごとに最初の1回だけログイン）
- 予備として、`setup` の実行ログに出る合言葉でも接続できます（設定画面の「接続の詳細設定」）

## Claude（AI）が予定を入れるとき

Googleカレンダーの「ラン計画」「勉強計画」「資金計画」「マイプラン」に入った予定は、アプリを開いたときに自動で取り込まれます。
- タイトルから読み取り：ラン「ラン 10km」→距離、勉強「簿記2級 60分」→科目と時間、資金「積み立て 30,000円」→金額
- タイトルの先頭に「✓」があれば実施済みとして取り込み
- ランは取り込み済みの予定でも、あとからタイトルの先頭に「✓」を付けると実施済みになり、実績が入る
  - 書き方：「✓ ラン 1.57km 21分47秒（予定 ラン 4km ジョグ30分）」→ 距離1.57km・21分47秒（「（予定」より後ろは読まない）
  - 走ったあとのスクショをClaudeに渡すと、その日の予定のタイトルをこの形に書き換える運用
- Googleカレンダー側で日時を変えた場合は、アプリにも反映（繰り返し予定は取り込みません）

## Code.gs を直したとき

「デプロイ」→「デプロイを管理」→ 鉛筆マーク → バージョン「新バージョン」→「デプロイ」。URLは変わりません。

## iPhoneのホーム画面に置く

SafariでアプリのURLを開き、共有ボタン →「ホーム画面に追加」。

## ホーム画面ウィジェット（Scriptable）

`widget/myplan-widget.js` を、無料アプリ「Scriptable」で動かすと、今日の予定と今月のまとめ（ラン・勉強・資金）をウィジェットで表示できます。小・中・大・特大（iOS 27以降）に対応、明るい／暗い表示にも自動で対応します。

1. App Storeで「Scriptable」を入れる
2. iPhoneで https://nakazu210.github.io/my-plan/widget.html を開き（アプリの設定画面からも開ける）、「プログラムをコピー」を押す
3. Scriptableで右上の「＋」→ 貼り付け → 上の題名を「マイプラン」にして「Done」
4. 「マイプラン」をタップして実行 → 接続先URL（/exec）と合言葉（setup の実行ログに出たもの）を入力
5. ホーム画面を長押し →「＋」→ Scriptable のウィジェットを置く → 長押し「ウィジェットを編集」→ Script で「マイプラン」を選ぶ

- URLと合言葉はiPhoneのキーチェーン（安全な保管場所）にだけ保存され、プログラムには書かれません
- 更新はおよそ30分ごと（iPhoneの判断で前後します）。通信できないときは前回の情報を表示します
- タップするとマイプランが開きます
