# マイプラン

ラン・勉強・資金づくりの計画と記録をまとめるカレンダーアプリです。
見た目はGoogleカレンダー風で、iPhone Duoの「閉じた画面（1列）」と「開いた画面（左右2画面）」に合わせて自動で切り替わります。

## できること

- 予定・記録の種類：ラン／勉強／資金／その他
- 予定ごとに、Googleカレンダーへの同期先を選べる
  - **アプリだけ**：このアプリにだけ残す
  - **自分のカレンダー**：自分専用の「ラン計画」「勉強計画」「資金計画」「マイプラン」カレンダーに入れる（妻には見えない）
  - **夫婦の共有カレンダー**：妻と共有しているカレンダーに入れる
- 夫婦の共有カレンダーの予定も、灰色で一緒に表示（見るだけ）
- 「まとめ」で、月のラン距離・ペース、勉強時間・試験までの日数、資金の達成率を表示

## しくみ

| 部分 | 置き場所 |
|---|---|
| 画面（index.html・style.css・app.js） | GitHub Pages |
| データ保存とカレンダー連携（gas/Code.gs） | 本人のGoogleアカウントの Apps Script |
| データ本体 | Googleスプレッドシート「マイプラン データ」 |

- Googleとつなぐ前は「お試し表示」（端末の中だけで動く見本データ）になります
- 接続には「接続先URL」と「合言葉」が必要です。合言葉はファイルに書かず、アプリの設定画面にだけ入力します

## 初回セットアップ（Google側・本人操作）

1. パソコンで https://script.google.com を開き、「新しいプロジェクト」
2. プロジェクト名を「マイプラン」にする
3. 最初から入っている文字をすべて消し、`gas/Code.gs` の中身をまるごと貼り付けて保存
4. 左の歯車（プロジェクトの設定）で、タイムゾーンが「(GMT+09:00) 日本標準時 - 東京」になっているか確認
5. 上の関数の選択で `setup` を選んで「実行」→ Googleの許可画面が出たら許可
   - 「このアプリはGoogleで確認されていません」と出たら「詳細」→「マイプラン（安全ではないページ）に移動」→「許可」
6. 下の実行ログに出た **合言葉** を控える（カレンダー4つとスプレッドシートが自動で作られます）
7. 右上の「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
8. 表示された「ウェブアプリのURL」（…/exec で終わる）を控える
9. アプリを開き、右上の歯車 → 接続先URLと合言葉を入力 →「接続テスト」→ 夫婦の共有カレンダーを選んで「保存」

※「全員」にしても、合言葉を知らない人はデータを読めません。

## Code.gs を直したとき

「デプロイ」→「デプロイを管理」→ 鉛筆マーク → バージョン「新バージョン」→「デプロイ」。URLは変わりません。

## iPhoneのホーム画面に置く

SafariでアプリのURLを開き、共有ボタン →「ホーム画面に追加」。
